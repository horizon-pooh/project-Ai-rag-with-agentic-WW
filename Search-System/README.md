# Search System

A modular search engine built with Node.js and TypeScript.

## Tech Stack

- Node.js
- TypeScript
- Fastify
- Prisma
- REST API

## Search Strategies

### Exact Search

Matches queries directly against searchable product fields.

### Keyword Search

Splits the query into tokens and calculates relevance based on matching fields.

### Fuzzy Search

Handles partially matched words and spelling mistakes.

### Semantic Search

Planned future search strategy using embeddings and vector similarity.

## Ranking

Search results will be ranked using scores generated by each search strategy.

```text
Exact Score
    +
Keyword Score
    +
Fuzzy Score
    +
Semantic Score
    │
    ▼
Final Score
```

Search strategy weights and searchable field weights will be configurable.

## Data Sources

The search engine is designed to work independently from its data source.

```text
Search Engine
     │
     ▼
Product Repository
     │
     ├── Mock Repository
     │
     └── Prisma Repository
             │
             ▼
          Database
```

Mock data will be used during development.

Prisma integration will be prepared for connecting a real database later.

## Development

Install dependencies:

```bash
npm install
```

Create environment configuration:

```bash
cp .env.example .env
```

Start development server:

```bash
npm run dev
```

Type check:

```bash
npm run typecheck
```

Build:

```bash
npm run build
```

Start compiled application:

```bash
npm start
```
