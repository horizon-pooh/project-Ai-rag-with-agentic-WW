# หาหมวดด้วยเวกเตอร์

ใช้เมื่อชื่อหมวดยังจับคู่ไม่ชัดเจน ชื่อ/alias ที่ตรงและรหัสที่ตรวจแล้วใช้ทางเดิม ไม่ให้เวกเตอร์เปลี่ยนรหัสที่ไม่รู้จักหรือแก้ชื่อกำกวมแทนเอง

## การทำงาน

1. ตรวจโมเดลและเวกเตอร์หมวดว่าตรง profile, SHA256, hash, template และครบทุกหมวด
2. ปล่อย connection ฐานก่อนเรียก Qwen สร้างเวกเตอร์คำหมวด ใช้ prefix สำหรับ query ตาม profile
3. เปิด snapshot อ่านใหม่ ตรวจชื่อและความพร้อมซ้ำ แล้วให้ SQL จัดอันดับ cosine แบบตรง
4. คืนหมวดระดับสามสูงสุด 8 รายการ หรือใช้ขอบเขตที่เลือกไปค้นสินค้าและกรองตามทางเดิม

ชื่อ/aliases ที่ปรากฏในคำหมวดใช้จำกัดขอบเขต เช่น OLED ไม่รวม QLED และขาแขวนไม่รวมตัวทีวี หลายกลุ่มแยกด้วย `|`, `หรือ` หรือ ` or ` ได้ กลุ่มใดเลือกไม่ได้จะไม่ใช้ผลแค่บางกลุ่มแทน

## เปิดใช้

เก็บ profile เดิมใน `.env.embedding.local` และคัดลอกค่าฟีเจอร์แยก:

```bash
cp -n .env.category-semantic.example .env.category-semantic.local
npm run db:check-category-semantic -- --query "ทีวี OLED สำหรับดูหนัง"
npm run dev:semantic
```

ต้องติดตั้ง migration `0008` ก่อน เปิดโมเดลและรอ health พร้อมก่อน Node บน Mac ต้องมี tunnel ทั้งฐานและโมเดล `npm run dev` ปกติไม่โหลดไฟล์ฟีเจอร์เสริมให้เอง

## การเลือกหมวด

เปิดฟีเจอร์ด้วย `SEARCH_CATEGORY_SEMANTIC_ENABLED=true` ค่าเริ่มต้นเป็นการเสนอหมวดใน `needs_clarification` ให้เลือก ID ที่เหมาะสมหรือถามลูกค้าเพิ่ม

หากใช้เลือกอัตโนมัติต้องตั้ง `SEARCH_CATEGORY_SEMANTIC_AUTO_SELECT=true` พร้อม `MIN_SCORE`, `MIN_GAP` และ `CALIBRATION_ID` โดยใช้ชื่อเต็มที่ขึ้นต้น `SEARCH_CATEGORY_SEMANTIC_` ค่าต้องมาจากการวัดกับโมเดลและข้อมูลชุดนี้ คะแนนทดสอบไม่ใช่ค่าแนะนำใช้งานจริงหรือเปอร์เซ็นต์ความมั่นใจ

เวกเตอร์หมวดไม่ครบ เก่า หรือโมเดลไม่ตรง จะใช้ผลชื่อเดิมพร้อมเหตุผล provider ใช้เวลารวมไม่เกิน 5 วินาทีสำหรับการเตรียมคำหมวดและไม่ใช้ผล OR ที่สำเร็จมาแค่บางส่วน หากฐานผิดพลาดให้รายงาน `search_unavailable`

การเรียก SQL ใหม่ให้สิทธิ์ผ่านฟังก์ชันอ่านที่จำกัดผล ไม่เปิดตารางเวกเตอร์หรือข้อมูลโมเดลโดยตรงแก่ `search_api` การย้อน `0008` ลบเฉพาะฟังก์ชัน ต้องปิดฟีเจอร์ก่อนย้อน

การใช้เวกเตอร์หาหมวดไม่เปลี่ยน `semantic_available` เอง ค่านี้ขึ้นกับการจัดอันดับสินค้า หากเปิด product hybrid จะใช้ `semantic_query` หรือ `query` รวมอันดับตาม [คู่มือ RRF](product-hybrid-search.md)
