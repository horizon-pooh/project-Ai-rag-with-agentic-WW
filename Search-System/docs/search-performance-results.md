## แผนและสิทธิ์

คำสั่งอ่านประกอบใช้ดัชนีเดิมของ products, product_attribute_values, product_features และ product_search_documents เวลาอ่านที่วัดครั้งนั้นประมาณ 0.03–0.30 ms ส่วน keyword wrapper ประมาณ 48 ms ตัว wrapper ไม่เปิดเผย nested plan ทั้งหมด

ยังไม่มีหลักฐานจากชุดนี้ให้เพิ่มดัชนีหรือ HNSW จึงคง schema เดิม ไม่ใช้การเพิ่มดัชนีชดเชยเวกเตอร์ที่ยังไม่ครบ

บัญชีค้นหาเห็น draft 0 รายการ รวมข้อมูลประกอบของ draft probe อ่านโมเดล/เวกเตอร์โดยตรงและเขียนสินค้าไม่ได้ statement timeout คืน 57014 แล้ว connection ใช้ต่อได้

จำลองโมเดลขัดข้องเฉพาะ adapter ในตัวทดสอบ ได้ HTTP 200 พร้อม keyword fallback; ทำ query ใน transaction ของตัวทดสอบ timeout ได้ HTTP 503 search_unavailable และคำขอถัดไปกลับ 200 ไม่หยุดโมเดลจริง

## ขอบเขตผล

เป็นรอบสั้นบนข้อมูลและโมเดลที่อุ่นแล้ว รันแต่ละวิธีตามลำดับ มีผลจาก cache ของ PostgreSQL/ระบบปฏิบัติการด้วย ไม่ใช่ cold start หรือผลสุ่มสลับวิธี ไม่ใช่เพดาน throughput และยังไม่มี SLA ที่ตกลงไว้

ไม่เขียนฐาน ไม่เพิ่มดัชนี ไม่เผยแพร่ drafts รันใหม่บนเซิร์ฟเวอร์และจากผู้เรียกจริงหลัง deploy ก่อนกำหนดตัวเลขรับประกัน
