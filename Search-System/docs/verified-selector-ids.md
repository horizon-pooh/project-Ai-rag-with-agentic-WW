# ส่งรหัสแทนชื่อ

JSON รุ่น `1` รองรับทั้งชื่อ รหัส หรือทั้งคู่ ชื่อเดิมยังใช้งานได้ตามปกติ

| ช่อง | ความหมาย |
|---|---|
| `filters.category_query` | ชื่อหรือคำเรียกหมวด |
| `filters.category_ids` | รหัสหมวด 1–20 รายการ ไม่ซ้ำ |
| `filters.feature_queries_all` | ชื่อฟีเจอร์ที่ต้องมีครบ |
| `filters.feature_ids_all` | รหัสฟีเจอร์ที่ต้องมีครบ 1–20 รายการ |
| `filters.specs[].attribute_query` | ชื่อสเปก |
| `filters.specs[].attribute_id` | รหัสสเปก |

รหัสใช้ตัวพิมพ์ใหญ่ตามฐาน หมวดแม่ขยายตามโครงสร้างจริง สเปกแต่ละข้อมีชื่อหรือรหัสอย่างน้อยหนึ่งช่อง พร้อม `op`, `value` และหน่วยตามชนิดข้อมูล

เมื่อส่งชื่อและรหัสพร้อมกันต้องสอดคล้องกัน เช่น ชื่อทีวีรวมกับรหัสหมวด OLED ใช้จำกัดให้แคบลงได้ แต่ชื่อ OLED รวมกับรหัส QLED เป็นความขัดแย้ง ชื่อที่ยังจับคู่ไม่ได้จะไม่ถูกละทิ้งเพราะมีรหัสมาแล้ว

รหัสสเปกและฟีเจอร์ต้องใช้กับหมวดนั้นได้ รายการชื่อฟีเจอร์กับรายการรหัสเป็นเงื่อนไข AND แยกกัน ไม่จับคู่ตามตำแหน่งในรายการ

รหัสไม่รู้จักให้เลือกใหม่ ไม่แก้เป็นรหัสคล้ายกันเอง การส่งรหัสข้ามการจับคู่ชื่อได้ แต่ยังตรวจสิทธิ์ ชนิดค่า และหน่วยทั้งหมด

ใช้ migration `0005` แล้วตรวจ:

```bash
npm run db:check-selector-ids
```

ตัวอย่างอยู่ใน `examples/tool-search-v1/request-with-ids.json` และ `request-ids-only.json` รหัสในตัวอย่างต้องตรวจความหมายจากฐานก่อนนำไปใช้
