# ข้อมูลสำหรับจับคู่คำค้น

ใช้ aliases ของหมวดและสเปก ร่วมกับ views `category_search_catalog`, `category_attribute_search_catalog` และตาราง `unit_conversion_rules` ที่มีอยู่

Migration `0002` เพิ่มฟังก์ชันใน `catalog_search`:

- `normalize_label` จัดตัวพิมพ์และช่องว่างของชื่อ
- `category_label_matches` จับคู่รหัส ชื่อ และคำเรียกหมวด
- `attribute_label_matches` จับคู่สเปกภายในหมวด
- `convert_unit` แปลงหน่วยตามคู่ที่เปิดใช้งาน
- `metadata_version` และ `metadata_audit` ตรวจรุ่นข้อมูลและจุดที่ยังขาด

ค่าตัวเลขภายในเก็บเป็นข้อความทศนิยมเพื่อรักษาความละเอียด การจัดรูปคำใช้กับชื่อเท่านั้น ไม่ใช้เปลี่ยนเลข รุ่นสินค้า หรือสัญลักษณ์หน่วย

แปลงหน่วยเฉพาะคู่ที่ระบุไว้ ไม่เดาการแปลง ไม่ต่อหลายกฎเอง และไม่แปลง kg เป็น L ค่าไม่ทราบยังเป็น `null` ส่วนศูนย์เป็นค่าจริง

ตรวจหลังติดตั้ง:

```bash
npm run db:check-metadata
```

ฟังก์ชันอ่านข้อมูลตามสิทธิ์ผู้เรียก ไม่เพิ่มตารางหรือ seed สินค้า การย้อนขั้นนี้ต้องถอน migration ที่พึ่งพาก่อน
