# หาหมวดจากชื่อและรหัส

`resolveCategoryQuery` รับข้อความหมวดไม่เกิน 200 ตัวอักษร แยกได้สูงสุด 5 กลุ่มด้วย `|`, `หรือ` หรือ ` or ` โดยไม่แยกคำว่า “และ” เครื่องหมายจุลภาค หรือเครื่องหมายทับเอง

ลำดับการจับคู่คือ รหัส → ชื่อ/alias ที่ตรง → คำสะกดคล้าย รหัสที่ไม่มีอยู่จะไม่ถูกเปลี่ยนเป็นหมวดอื่น

- หมวดแม่ขยายไปหมวดย่อยระดับสามตาม `parent_id`
- OLED ไม่รวม QLED หรืออุปกรณ์เสริม
- หลายกลุ่มใช้ OR และตัดรหัสหมวดซ้ำ
- ชื่อกำกวมหรือมีหนึ่งกลุ่มที่ยังเลือกไม่ได้ จะคืน `needs_clarification` ทั้งคำขอ
- ชื่อซ้ำที่ขยายแล้วได้ขอบเขตเดียวกันรวมกันได้ แต่ไม่เลือกแถวแรกเมื่อขอบเขตต่างกัน

Migration `0003` เพิ่ม `category_candidates` และ `category_leaf_scopes` คำสะกดคล้ายใช้ pg_trgm ตั้งค่าเริ่มต้น 0.35 และคืนได้สูงสุด 8 หมวดผ่านตัวเชื่อม ค่านี้เป็นเกณฑ์หาตัวเลือก ไม่ใช่ความมั่นใจหรือสิทธิ์เลือกแทนลูกค้า

การขยายหมวดตรวจโครงสร้างสามระดับก่อน หากโครงสร้างเสียให้รายงานข้อผิดพลาด ไม่คืนขอบเขตบางส่วน

```bash
npm run db:check-categories
```

ใช้ SQL แบบส่งค่าเป็นพารามิเตอร์และอ่านใน snapshot เดียวกัน ขั้นนี้ไม่อ่านสินค้าทั้งฐาน ส่วนเวกเตอร์ดู [การหาหมวดด้วยเวกเตอร์](category-semantic-resolution.md)
