# ผลประเมิน 29 ต.ค. 2026

ฐานจริงชุด published 90 รายการใน 6 หมวด: เครื่องซักผ้าฝาหน้า หม้อหุงข้าวดิจิตอล กาต้มน้ำ ตู้เย็น 2 ประตู เครื่องปิ้งขนมปัง และเครื่องฟอกอากาศ ทั้งหมดเป็นข้อมูลจำลองที่เผยแพร่แล้ว

ผลนี้สนับสนุนการใช้ hybrid ในคำค้นตัวเลขของชุดที่วัด ยังไม่สรุปแทน 1,907 ประเภทหรือการใช้งานกว้างทุกแบบ เวกเตอร์หมวดยังไม่ครบและไม่ได้เปิด semantic category อัตโนมัติ ชุด fixture 139 กรณีใช้ตรวจ regression เท่านั้น

ตัวเลขอาจเปลี่ยนเมื่อแก้ข้อมูลหรือโมเดล ก่อนใช้กับลูกค้าควรเพิ่มคำค้นด้านการใช้งานที่คนให้คะแนน รวมคำกำกวมและคำที่ไม่มีสินค้าที่เหมาะสม การวัดความเร็วและ query plan อยู่ Commit 26
