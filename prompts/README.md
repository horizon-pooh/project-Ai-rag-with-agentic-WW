# prompts/

prompt และรายการคำของกฎในโค้ด แก้ได้โดยไม่แตะโค้ด

สถานะ: ไฟล์กฎมีรายการแล้ว (มีเคสทดสอบ) — `system.md` ยังว่าง (รอคำตอบ)

| ไฟล์ | ใช้ที่ | หมายเหตุ |
|---|---|---|
| `system.md` | `services/ai_client.py` | ยังไม่มี — รอรูปแบบ AI API (อาจไม่ต้องใช้ถ้า API ถือ prompt เอง) |
| `rules/resume_ai.txt` | `pipeline/steps/handoff_check.py` | คำสั่ง "คุยกับ AI" (ตรงทั้งข้อความหลัง normalize) |
| `rules/escalate.txt` | `pipeline/steps/rules.py` | ร้องเรียน / เคลม / ขอคน -> ส่งต่อทันที |
| `rules/faq.txt` | `pipeline/steps/rules.py` | FAQ / ทักทาย -> ตอบเองไม่ใช้ AI |

กติกาไฟล์กฎ:
- หนึ่งบรรทัดหนึ่งรายการ, บรรทัดที่ขึ้นต้นด้วย `#` เป็นคอมเมนต์
- เขียนรายการในรูปที่ normalize แล้ว (NFC, ไม่มี zero-width, ไม่มีช่องว่าง, ตัวพิมพ์เล็ก)
- **ทุกรายการต้องมีเคสทดสอบภาษาไทยจริง** ใน `tests/` — ภาษาไทยไม่มีช่องว่างคั่นคำ จับสตริงพลาดง่าย (เช่น "ตู้เย็น" ไปตรง "ตู้เสื้อผ้า")
- ห้ามแก้การจับพลาดด้วยการเพิ่มคำไปเรื่อยๆ โดยไม่มีเคสทดสอบ

แนวคิดจาก: `src/ai/prompts/README.md`, `src/pipeline/filter.js` (แบบเก่า)
