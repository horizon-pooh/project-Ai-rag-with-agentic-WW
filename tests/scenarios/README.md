# tests/scenarios/

ชุด regression 30 บทสนทนา

สถานะ: ยังไม่มีข้อมูล

| ข้อตกลง | รายละเอียด |
|---|---|
| จำนวน | 30 บทสนทนา จากแชทจริง (redact แล้ว) |
| ควรส่งต่อ | ราว 10 เคส (ร้องเรียน, เคลม, ขอคน, AI ตอบไม่ได้) |
| ป้าย | ติดป้ายเส้นทางที่ถูก (ตอบเอง / ถามกลับ / ส่งต่อ) **ก่อนเขียนโค้ด** |
| เมื่อไหร่รัน | ทุกครั้งที่แก้ prompt, ไฟล์กฎ หรือเปลี่ยน AI API |
| ผลที่ดู | เส้นทางตรงป้าย, ไม่ส่งต่อขาด (ควรส่งแต่ตอบไป), ส่งต่อเกิน |

รูปแบบไฟล์ยังไม่กำหนด (เสนอ: หนึ่งไฟล์ต่อบทสนทนา มีข้อความลูกค้าตามลำดับ + ป้ายที่คาด)
