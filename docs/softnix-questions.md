# คำถามที่ต้องส่ง Softnix (ส่งก่อนเริ่มเขียนโค้ด)

คำตอบของข้อ 1–2 ตัดสินว่า Softnix รับคำถามสินค้าทั้งหมดไหวไหม
คำตอบของข้อ 3–7 ตัดสินว่าจะกลับไปให้ Softnix ส่ง LINE เองได้หรือไม่ (ดู `decisions.md` D-003)

ขอคำตอบเป็นลายลักษณ์อักษร

---

### ความเร็วและปริมาณ

1. ตอนนี้ endpoint `/chat/completions` ของเรารับงานพร้อมกันได้กี่งาน (วัดได้ว่าทำทีละ 1 งาน ส่ง 3 งานพร้อมกัน งานที่ 3 หมดเวลาที่ 304 วินาที) **เพิ่มได้ไหม เพิ่มได้ถึงเท่าไหร่**
2. คำถามค้นสินค้า 1 ครั้ง **รับประกันเวลาได้ไหม** (วัดได้ 100–230 วินาที) มีทางทำให้เร็วขึ้นไหม เช่น ปิดบางขั้นตอน หรือมี endpoint ค้นสินค้าตรงๆ ที่ไม่ผ่าน LLM

### ถ้าจะให้ Softnix ส่ง LINE เอง (ต้องได้ "ได้" ครบทุกข้อ)

3. เก็บ secret (LINE channel access token) ไว้ในระบบ Softnix ได้ไหม **โดยไม่ต้องใส่ใน prompt**
4. ระบบ Softnix ยิง `POST https://api.line.me/v2/bot/message/push` เองได้ไหม
5. ส่ง Flex Message (JSON การ์ดสินค้า) ได้ไหม หรือได้แค่ข้อความธรรมดา
6. แจ้งผลกลับมาที่ endpoint ของเรา (callback) ได้ไหม ว่าตอบสำเร็จ / ตอบไม่ได้
7. **ก่อนส่งทุกครั้ง** ถามระบบเราได้ไหมว่า "ลูกค้าคนนี้ยังส่งได้อยู่ไหม" (เพราะลูกค้าอาจถูกส่งต่อเจ้าหน้าที่ระหว่างที่รอ)

### อื่นๆ

8. ถ้าส่ง LINE userId ไปด้วย Softnix เก็บข้อมูลลูกค้าไว้ไหม เก็บนานเท่าไหร่ (เรื่อง PDPA)
9. ราคาและสต็อกใน catalog ของ Softnix อัปเดตบ่อยแค่ไหน
