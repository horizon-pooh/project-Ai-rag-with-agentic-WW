02 · LAYER STACK · SRC/

โครงสร้างโค้ด 6 ชั้น

โฟลเดอร์ใน src/ เรียงเป็นชั้นตามทางที่ข้อความเดินผ่าน ตั้งแต่รับ webhook ลงไปถึงที่เก็บข้อมูล ชั้นที่ 05 (ขาออก) คือชั้นที่ผิดพลาดไม่ได้ เพราะเป็นจุดเดียวที่ตัดสินว่าข้อความถึงลูกค้าหรือไม่

LAYER 05

ทำไมขาออกสำคัญที่สุด

  • ทุกข้อความไปหาลูกค้าต้องเรียก sendGuard ห้ามเรียก lineApi ตรง
  • กันคำตอบ Softnix ที่มาช้า ไม่ให้แทรกตอนเจ้าหน้าที่ดูแลอยู่ (ดูภาพ 03)
  • เทสต์ชั้นนี้ก่อนชั้นอื่น: test/unit/sendGuard.test.js

LAYER 04

ทำไมแยกงานนานออกมา

  • Softnix ใช้ 100–230 วินาที ถ้ารอใน request จะค้าง
  • คิวอยู่ใน Redis restart แล้วงานไม่หาย
  • catalog/ ว่างไว้ ถ้าตัวเลขจริงบอกว่า Softnix ไม่ไหว
