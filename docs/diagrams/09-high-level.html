ระบบทั้งหมดในหน้าเดียว

ข้อความจาก LINE เข้าทาง Caddy → API จดลง Postgres ซึ่งเป็นทั้งฐานข้อมูลและคิวงาน → Worker หยิบไปตัดสินใจ ถาม AI gateway ของบริษัท แล้วตอบกลับทาง LINE ส่วนเรื่องที่ครอบทุกส่วน (งานตามเวลา ความปลอดภัย เฝ้าระวัง backup) อยู่ในแถบด้านขวาและแถวล่าง

อ่านภาพนี้ยังไง

  • แถบบนสุด = ช่วงงานซ้ายไปขวา กล่องในคอลัมน์เดียวกันอยู่ช่วงเดียวกัน
  • กรอบทึบ = เครื่อง server ของเรา (Docker Compose เครื่องเดียว) กรอบประ = ข้างนอก (LINE, call center, AI ของบริษัท)
  • แถบในกรอบด้านบน = งานตามเวลาที่ worker รันเอง ไม่ได้มาจากลูกค้า
  • 3 แถวล่าง = เรื่องที่ครอบทุกส่วน คู่กับแถบแนวตั้งด้านขวา
  • ดูรายละเอียดเพิ่ม: ทีละขั้นที่ภาพ 02, deploy ที่ภาพ 07, ฉบับอ่านง่ายที่ภาพ 08

ทำไม Postgres เป็นจุดสีแดง

ทุกอย่างผ่านที่นี่: ข้อความดิบ, สถานะ bot/human, แชทย้อนหลัง, คิวงาน (procrastinate) และ replyToken ไม่มี Redis แล้ว (D-010)

ข้อดี: service น้อย ข้อมูลกับคิวไม่หลุดกัน · ข้อเสีย: Postgres ล่ม = รับข้อความได้แต่ตอบไม่ได้ทั้งระบบ จึงมี backup รายคืนและ watchdog แจ้งเมื่อ DB ต่อไม่ได้

ยังไม่รู้ / ยังไม่ทำ

  • ช่องทางแจ้ง call center (ตอนนี้ log) รอคำตอบ
  • เครื่องปลายทาง backup + SMTP แจ้งเตือน รอคำตอบ
  • AI รับรูปได้ไหม / รับงานพร้อมกันกี่งาน รอคำตอบ
  • ยังไม่เคยรันกับ LINE / Docker จริง
