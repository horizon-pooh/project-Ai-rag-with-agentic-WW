01 · ARCHITECTURE · LINE_PROD

ภาพรวมระบบบน server บริษัท

ระบบเราอยู่ระหว่าง LINE กับ Softnix บน server บริษัทเครื่องเดียว (pm2 + Redis) จุดสำคัญคือ sendGuard ซึ่งเป็นทางเดียวที่ข้อความออกไปหาลูกค้า และเส้นประด้านล่างคือทางหลบ: เมื่อเปิด kill switch ข้อความทั้งหมดไปที่ call center ตรงๆ เหมือนก่อนมีระบบนี้

PRINCIPLE

ทุกข้อความขาออกผ่าน sendGuard

  • Softnix ไม่ส่ง LINE เอง — ตอบกลับมาที่ worker ของเรา แล้ว sendGuard ตัดสินว่าจะส่งไหม
  • token ของ LINE อยู่ใน .env ของเราที่เดียว (src/line/lineApi.js)
  • เหตุผลเต็มอยู่ที่ docs/decisions.md D-003 (รอยืนยัน)

OPEN

เส้นประ = ต้องถามก่อน

  • webhook URL ของ LINE ต้องชี้มาที่เรา เพราะเราเป็นคนแยกทาง AI / call center (open-questions.md ข้อ 1, decisions.md D-007)
  • ข้อความวิ่งไป call center ทางไหน (ข้อ 3)
  • ทางหลบตอน server เราตายทั้งเครื่อง (ข้อ 10)

CUT

ไม่ได้วาด

  • pipeline ข้างใน app (dedupe, userQueue, filter) — ดูภาพ 02
  • dev/ และ test/ — ไม่ขึ้น production
