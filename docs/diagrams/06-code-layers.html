โครงสร้างโค้ด app/

โค้ดเรียกจากบนลงล่างเท่านั้น pipeline/ เป็นชั้นที่ตัดสินทุกอย่าง ส่วนที่คุยกับโลกภายนอกแยกเป็น services/ (API ภายนอก) กับ repositories/ (SQL) จึงสลับผู้ให้บริการหรือจำลองในเทสต์ได้ที่เดียว

กติกาของชั้น

  • api → worker → pipeline → services / repositories ชั้นล่างไม่ import ชั้นบน
  • มีแต่ repositories/ ที่เขียน SQL
  • pipeline/ รับตัวช่วยผ่าน deps ไม่เรียก LINE ไม่เขียน SQL เอง
  • orchestrator บันทึก ai_steps แต่ละ step ไม่บันทึกเอง
  • ข้อความถึงลูกค้าออกทาง steps/send.py เท่านั้น — แจ้งผู้ดูแล (services/alert) ไม่ใช้ LINE

ไฟล์ที่ไม่ได้อยู่ใน app/

  • prompts/rules/: escalate · faq · resume_ai ทุกคำต้องมีเคสทดสอบภาษาไทย
  • prompts/system.md: system prompt (ส่งเมื่อตั้ง AI_SYSTEM_PROMPT_FILE)
  • app/static/no-image.png: รูปแทนบนการ์ดสินค้า
  • migrations/: .sql + dbmate (รวม schema ของ procrastinate)
  • tests/: pytest + respx (คนละที่กับ test/ ของแบบเก่า)

สถานะ

มีโค้ดครบทุกชั้น เทสต์ 944 ผ่าน (SQL ทดสอบกับ Postgres 16 จริงผ่าน pgserver) — ยังไม่เคยรันกับ LINE / Docker จริง ดูหน้าที่รายไฟล์ใน filemap.md

ไฟล์ JS เดิมใน src/ เป็นแบบเก่า ห้ามแก้
