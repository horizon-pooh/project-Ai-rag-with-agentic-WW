# src/catalog/  (ยังว่าง — เผื่อไว้)

ที่สำหรับ **ค้นสินค้าจาก catalog โดยตรง** (หมวด / ยี่ห้อ / ช่วงราคา / คำไทย) ตอบได้ในเสี้ยววินาที
แทนการส่งทุกคำถามสินค้าไป Softnix ที่ใช้ 100–230 วินาทีและทำได้ทีละคิว

จะเริ่มทำก็ต่อเมื่อตัวเลขจริงบอกว่า Softnix รับไม่ไหว (ดู `docs/softnix-questions.md` และ `docs/open-questions.md` ข้อ 5)
เตรียมโฟลเดอร์ไว้ก่อน จะได้เพิ่มทีหลังโดยไม่ต้องรื้อโครงสร้าง
